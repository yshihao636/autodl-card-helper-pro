AutoDL 抢卡与克隆助手 Pro v1.1.0

支持系统盘 + 数据盘完整克隆 · 指定目标服务器 (machine_id / 编号) · 稀疏文件优化 (ft_sparse) · 折后单价过滤 · SSH 一键切流

✓ 已复制到剪贴板，请打开 Tampermonkey 新建脚本粘贴保存
1. 安装 Tampermonkey 在 Chrome 或 Edge 扩展商店安装 Tampermonkey（油猴），并在浏览器扩展管理页开启「开发者模式 / 允许运行用户脚本」。
2. 新建并粘贴脚本 点击上方「一键复制油猴脚本代码」，打开 Tampermonkey 面板 → 点击「+ 添加新脚本」→ 全选替换原有代码 → 按 Ctrl+S 保存。
3. 打开 AutoDL 控制台使用 登录 AutoDL 实例列表，点击右下角「AutoDL 抢卡」即可选择源实例、勾选克隆模式并指定要抢的服务器。
